# Veritas Project Summary

Veritas | Trainable Evidence Retrieval, Cross-Encoder Ranking & Neural Fact Verification

Veritas is a Mac-first factual claim verification system built around reproducible retrieval, transformer verification, and citation-grounded explanations. The core focus is closing the gap between oracle (gold-evidence) and retrieved-evidence verifier performance through trainable retrieval and reranking.

## Final direction

- Verdict classification is handled by DistilRoBERTa or DeBERTa checkpoints, trained to be robust to retrieved (not just gold) evidence.
- Retrieval combines BM25, dense, and a fine-tuned bi-encoder with hybrid RRF fusion.
- A fine-tuned cross-encoder reranks retrieved evidence before it reaches the verifier.
- Explanations are generated by Qwen2.5 MLX LoRA in strict JSON form, with preference-guided reranking. This is an optional layer, not the source of truth for the verdict.
- Serving is through FastAPI and Gradio with caching, monitoring, and fallbacks.

## What exists

- Sample-scale FEVER and SciFact processed datasets under `data/processed/`
- Checked-in retrieval, ranking, verifier, faithfulness, and Pareto reports under `reports/`
- Clean DistilRoBERTa verifier checkpoint in `checkpoints/transformer_verifier_clean/`
- Lightweight sklearn verifier fallback in `checkpoints/verifier_clean/`
- MLX LoRA adapter in `checkpoints/mlx_lora_verifier/`
- Explanation-only SFT and preference reranking scripts
- Production-style API and UI entrypoints

## Reality check

The repository is research-grade, not SOTA.
The checked-in metrics are sample-scale and should be described honestly.
The final project scope is Mac-compatible and does not depend on CUDA, Kaggle, Colab, or bitsandbytes.

## Safe resume line

Veritas is a Mac-compatible research and production ML project for evidence-grounded fact verification, with hybrid retrieval, transformer verdict classification, MLX LoRA explanation generation, and preference-guided explanation reranking.
